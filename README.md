Proyecto ALMA

El Proyecto ALMA tiene como objetivo principal desarrollar una aplicación móvil interactiva, impulsada por Inteligencia Artificial y Machine Learning, diseñada para brindar un apoyo integral a tutores y cuidadores de niños con Síndrome de Down. Esta solución tecnológica busca democratizar el acceso a la intervención temprana desde el hogar, ofreciendo herramientas personalizadas que fortalezcan las habilidades para la vida diaria, promuevan la autonomía y faciliten la inclusión social, alineándose directamente con el Objetivo de Desarrollo Sostenible 10.2.
